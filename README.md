# Snake-game

rules:
apples falls from the top of the screen, eat it and don't let it reach the bottom.
don't run into walls.
it is ok to run into yourself, you will phase through.
after 10 apples are eaten, the speed will increase.

controls:
arrow keys to move the snake left, right, up, and down.
space bar to reset once gameover.

bugs:
sometimes if you eat an apple while going up, it won't register and will continue falling. up to chance.
if you press 2 arrow keys very fast it is possible to go into yourself and do a 180 along the same row/column.
